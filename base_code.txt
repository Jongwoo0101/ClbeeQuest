1. 주제: 커스텀 쉘 (bash/zsh/powershell) 위에서 돌아가는 한국공학대학교 ai소프트웨어학과 학생 전용 쉘

2. 핵심 기능
- 커스텀 명령어 (버스시간표, 식당메뉴표, 수업시간표, 날씨(시흥시 정왕동, 거북섬), 수강정보(수강중인 과목 정보제공 서비스))
- 기존 쉘 명령어 사용가능

3. 개발 방안
- 각 쉘별 각각 구현한다
 ->
우진 BASH
원종우 -> ZSH +
동현 -> POWERSHELL

4. 핵심 색상 조합
- 한국공학대의 색상 코드에 맞게 TU BLUE (#1758A8) TU SKY BLUE (#068FD3) TU MINT (#01B3CD)를 주로 사용하여 구현한다.
