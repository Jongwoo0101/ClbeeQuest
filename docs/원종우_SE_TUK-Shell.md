# 🧑‍💻 원종우 (MacBook / SE) — Data Structure & TUK Custom 파트

> 마감: 7월 17일(목) 오후 2시
> 환경: MacBook (자료구조/문자열 처리 위주라 독립적인 단위 테스트 수월)

## 담당 모듈
- `list.c` (또는 `process.c`)
- `tuk_custom.c`

## 착수 시점
이우진(A)의 `parser.h` 구조체가 확정되는 즉시 병렬로 시작.
단, **연결 리스트 파트는 이우진 결과물 없이도 오늘(7/15) 바로 시작 가능**하므로 먼저 착수 추천.

## 세부 업무

1. **구조체 설계**: `ProcessInfo` 구조체 정의
2. **연결 리스트 구현**: 백그라운드 프로세스 관리용 연결 리스트(Linked List)의 추가/검색/삭제 로직 개발 (메모리 누수 방지에 집중)
3. **정렬 알고리즘**: 이후 `top` 명령에서 사용할 정렬 기능(qsort 등) 뼈대 구현
4. **TUK 커스텀 명령어**: `schedule`, `bus`, `bob`, `notice`, `map` 등 캠퍼스 특화 명령어 구현 (더미 데이터 기반 출력) — 이 프로젝트의 킬링 포인트
