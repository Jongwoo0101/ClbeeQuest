## 세부 업무 (명세 1·5단계 기준)

1. **외부 명령어 실행 (1단계)**: `fork()`와 `execvp()`를 이용해 일반 외부 명령어(예: `ls -l`) 실행 로직 구현, 반환값 체크로 에러 처리 필수
2. **백그라운드 프로세스 처리**: 명령어가 `&`로 끝날 때 백그라운드로 넘기고, `waitpid(..., WNOHANG)` 등으로 좀비 프로세스(Zombie Process) 수거
3. **리눅스 /proc 파싱 (5단계)**: `/proc/[pid]/stat`, `/proc/[pid]/status` 파일을 파싱해 실제 CPU/메모리 사용량 추출 (Mac에서는 불가능한 작업)
4. **top 명령어 완성 (4단계 마무리)**: 원종우(B)가 만든 qsort 정렬 뼈대(`-cpu`, `-mem`, `-time` 옵션)에, 직접 파싱한 실제 시스템 리소스 데이터를 결합해 완성

## 장점
WSL/리눅스 환경에서만 가능한 핵심 시스템 콜 기능을 전담해 병목 현상 방지.

## 다른 팀원과의 접점
- **원종우(B)**: `top` 완성을 위해 B의 정렬 뼈대 함수 시그니처(어떤 데이터를 어떤 형태로 넘겨받을지)를 사전에 맞춰야 함
- **이우진(A)**: `&` 식별 자체는 A의 parser가 담당하지만, 실제 백그라운드 실행 및 종료 처리는 C가 담당 — Command 구조체의 `is_background` 필드를 넘겨받는 인터페이스를 A와 사전 합의 필요
