## 세부 업무

1. **외부 명령어 실행**: `fork()`와 `execvp()`를 이용해 일반 외부 명령어(예: `ls -l`) 실행 로직 구현
2. **백그라운드 프로세스 처리**: 명령어가 `&`로 끝날 때 백그라운드로 넘기고, `waitpid(..., WNOHANG)` 등으로 좀비 프로세스(Zombie Process) 수거
3. **리눅스 /proc 파싱**: `/proc/[pid]/stat` 파일 등을 파싱해 프로세스의 실제 CPU/메모리 사용량 추출 (Mac에서는 불가능한 작업)
4. **top 명령어 완성**: 원종우(B)가 만든 정렬 알고리즘 뼈대에, 직접 파싱한 실제 시스템 리소스 데이터 결합
