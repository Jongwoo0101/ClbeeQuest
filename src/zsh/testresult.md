## 🛠️ 단계별 상세 구현 및 검증 리포트

### ✅ 1단계: 기본 REPL 루프 (완료)

* **주요 내용:** `main.c` 등 모듈화, 프롬프트 컬러(TU BLUE) 적용, 파싱 로직, `cd/pwd/exit/help` 내장 명령어 처리.

### ✅ 2단계: 구조체 + 연결 리스트 (완료)

* **주요 내용:** `ProcessInfo` 구조체 정의, 동적 연결 리스트 관리, `waitpid(-1, &status, WNOHANG)`를 이용한 메모리 누수 방지 및 프로세스 상태 갱신(Reaping) 구현 완료.

### ✅ 3단계: `jobs` 검색 (완료)

**1. 구현 내용 요약**

* **목록 순회 및 출력:** 연결 리스트를 순회하며 `JOB#`, `PID`, `STATUS`, `START_TIME`, `COMMAND` 등을 지정된 포맷으로 표출.
* **옵션 파싱:** `argv`를 순회하며 `-pid`와 `-name` 옵션에 따른 분기 처리 완료.
* **검색 알고리즘:** PID는 일치 여부 확인, Name은 `strstr`을 활용한 부분 문자열 매칭(Substring Matching) 구현.

**2. 단계 검증 (8대 추가 테스트 Pass 완료)**

* [x] **전체 목록:** `jobs` 입력 시 전체 목록이 표 형식으로 누락 없이 출력됨.
* [x] **빈 목록 처리:** 백그라운드 작업이 없을 때 `No background jobs.` 메시지 정상 출력.
* [x] **PID 정확 검색:** `jobs -pid PID` 입력 시 정확히 해당 1건 표출 (없을 시 `No matching job found.`).
* [x] **PID 옵션 예외:** 숫자가 아닌 값이나 인자 누락 시 `invalid jobs option` 등 방어 로직 정상 작동.
* [x] **이름 부분 매칭:** `jobs -name KEYWORD` 입력 시 부분 문자열 기준으로 정확히 필터링되어 출력.
* [x] **명령어 옵션 예외:** `-foo` 등 존재하지 않는 옵션 입력 시 사용법 정상 안내.
* [x] **백그라운드 예외:** `jobs &` 실행 시 내장 명령어 백그라운드 실행 금지 룰 정상 적용.
* [x] **갱신 후 축소:** 백그라운드 작업 완료 후 상태 갱신(Reaping) 사이클을 거치면 `jobs` 목록에서 정상적으로 제외(삭제)됨.
