## 🛠️ 단계별 상세 구현 및 검증 리포트

### ✅ 1단계: 기본 REPL 루프 (완료)

* **주요 내용:** `main.c` 등 모듈화, 프롬프트 컬러(TU BLUE) 적용, 파싱 로직, `cd/pwd/exit/help` 내장 명령어 처리.

### ✅ 2단계: 구조체 + 연결 리스트 (완료)

* **주요 내용:** `ProcessInfo` 구조체 정의, 동적 연결 리스트 관리, `waitpid(-1, &status, WNOHANG)`를 이용한 메모리 누수 방지 및 프로세스 상태 갱신(Reaping) 구현 완료.

### ✅ 3단계: `jobs` 검색 (완료)

* **주요 내용:** 연결 리스트 순회 출력, PID 정확 검색, Name 부분 문자열(`strstr`) 검색 로직 구현 및 예외 처리 완비.

### ✅ 4단계: `top` 정렬 (완료)

**1. 구현 내용 요약**

* **배열 복사 및 정렬:** 원본 연결 리스트의 훼손(링크 깨짐)을 막기 위해 노드 포인터용 배열을 동적 할당하여 복사한 후 `qsort`를 수행.
* **비교 콜백(Callback) 구현:** CPU(`cmp_cpu`), 메모리(`cmp_mem`), 실행시간(`cmp_time`) 기준 내림차순 정렬 로직 완성.
* **메모리 제어:** 정렬 및 출력이 끝난 동적 배열을 즉시 `free()` 처리하여 메모리 누수 완벽 방지.

**2. 단계 검증 (7대 핵심 테스트 Pass 완료)**

* [x] **시간 정렬 (핵심):** `top -time` 실행 시 가장 오래 실행 중인(먼저 등록된) 작업이 상단에 정상 정렬됨.
* [x] **기본 동작 확인:** `top -cpu`, `top -mem` 정상 출력 (스텁 상태에 따른 0.0/0 출력은 5단계 연동 전 정상 동작으로 확인).
* [x] **빈 목록 처리:** 활성 작업이 없을 때 `No background jobs.` 메시지 정상 출력.
* [x] **인자 예외:** 옵션 누락 또는 2개 이상 입력 시 사용법 정상 안내.
* [x] **옵션 예외:** `-foo` 등 잘못된 옵션 입력 시 `invalid top option` 오류 정상 출력.
* [x] **백그라운드 예외:** `top -cpu &` 등 내장 명령어 백그라운드 금지 규칙 정상 적용.
* [x] **원본 리스트 보존 (핵심):** `top` 수행 후 `jobs`를 다시 입력했을 때 원래의 프로세스 등록 순서(JOB#)가 완벽히 유지됨.
