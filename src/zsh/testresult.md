## 🛠️ 단계별 상세 구현 및 검증 리포트

### ✅ 1단계: 기본 REPL 루프 (완료)

**1. 구현 내용 요약**

* **모듈화 완료:** `main.c`(65줄, 100줄 제한 통과), `parser.c`, `commands.c`, `executor.c`로 분리.
* **UI 적용:** `TUK-OS > ` 프롬프트에 **TU BLUE** 컬러 적용. 백그라운드 시도 메시지에 **TU SKY BLUE** 컬러 적용.
* **명령어 파싱:** 입력 → 토큰화 → `&` 플래그 검사 처리 (`parser.c`).
* **내장 명령어:** `cd`, `pwd`, `help`, `exit` (인자 검증 + usage 메시지 + `perror` 에러 처리 완료). 내장 명령어는 백그라운드(`&`) 실행 금지 예외 처리.
* **외부 명령어:** `fork()` + `execvp()` 실행. 포그라운드 작업은 `waitpid()`로 대기.
* **예외 처리:** 입력 길이 초과, 토큰 수 초과, MAX_ARGS 초과 등 방어 로직 적용.

**2. 빌드 및 실행 방법**

```zsh
cd src/zsh
unzip tuk-shell-zsh.zip
make
./tuk_shell

```
